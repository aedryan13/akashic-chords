On-device picture cut-outs for the Graphics studio (Remove background, Smart layers).
MediaPipe Tasks Vision 0.10.14 (Apache License 2.0, Google LLC): vision_bundle.mjs, vision_wasm_internal.js/.wasm.
Models (Apache License 2.0, Google LLC, from storage.googleapis.com/mediapipe-models): selfie_segmenter.tflite (people),
magic_touch.tflite (tap a thing to pick it), deeplab_v3.tflite (21 kinds of things for Smart layers).
Nothing leaves the device. Files are fetched from this folder the first time they are used, then kept offline.
