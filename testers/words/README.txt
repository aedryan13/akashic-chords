words.json is built by build_words.py from:
- CMU Pronouncing Dictionary (BSD-2-Clause, Carnegie Mellon University), via the npm package cmu-pronouncing-dictionary (ISC): rhymes and syllable counts.
- SUBTLEX-US word frequencies (Brysbaert & New), via the npm package subtlex-word-frequencies: keeps the 26,000 most common words.
- Princeton WordNet 3.1 (WordNet License, free to use and redistribute with this notice), via the npm package wordnet-db: words with the same meaning.
